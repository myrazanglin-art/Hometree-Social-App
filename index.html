A privacy-first matchmaking platform moving away from superficial swiping. Connecting souls through shared tastes in books, movies, and music.

👤 My Role

Product Lead & Full-Stack Developer (University Innovation Competition)

🚀 Key Product Decisions

  • Niche Positioning: Identified the gap for "slow dating" among subculture enthusiasts (indie music, art films) tired of traditional dating apps.
  • AI Integration: Designed AI-powered ice-breaking mechanics using LLMs to suggest conversation starters based on shared interests.
  • Privacy-First Architecture: Users are matched based on high-dimensional vector similarity, not photos.

🛠️ Tech Stack & Architecture

Python Flask MySQL Cosine Similarity OpenAI API

⚙️ Core Matching Logic

  1. Feature Extraction: User inputs (books, movies, music) are mapped to a high-dimensional vector space.
  2. Cosine Similarity: Calculating the angle between two users' interest vectors.
  3. Threshold Filtering: Users with a similarity score above a specific threshold are pushed to the recommendation pool.
